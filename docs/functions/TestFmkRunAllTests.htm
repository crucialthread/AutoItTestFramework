Function Reference

_TestFmkRunAllTests

Runs the test suite function only when the script is executed directly, not when it is included by another script.

#include <TestFramework.au3>
_TestFmkRunAllTests ( $hRunnerFunction [, $sScriptName = @ScriptName] )

Parameters

$hRunnerFunctionA function reference to the test suite function to call. Pass the function name directly without parentheses or quotes (e.g. _RunMyTests, not "_RunMyTests" or _RunMyTests()).
$sScriptName[optional] The name of the test file. Defaults to @ScriptName. The test suite function is only called when @ScriptName matches this value. Pass the test file name so the AutoIt Test Framework can run the function only when the script is executed directly.

Return Value

None.This function does not return a value.

Remarks

Place a single call to _TestFmkRunAllTests() at the bottom of every test file. It compares @ScriptName against $sScriptName and only calls the test suite function when they match - meaning when the test file is run directly. When the test file is included in a script that includes all test files, @ScriptName will be that script's file name, not the test file's name, so the test suite function will not run automatically.

It is recommended to declare a Local Const at the top of the test file holding the file name, and pass it to both _TestFmkRunAllTests() and each _TestFmkAssert() call. This ensures failure output correctly identifies which file each assertion came from when running in a combined context.

Related

_TestFmkRun, _TestFmkAssert, _TestFmkSummary, _TestFmk_SetSilentMode

Example

#include <TestFramework.au3>
#include "MathLib.au3"

Local Const $MATH_LIB_TESTS = "MathLibTests.au3"

Func _TestAdd()
    _TestFmkHeader("Test: Add() - returns correct sum")
	
    Local $vResult = Add(2, 3)
	
    _TestFmkAssert($vResult = 5, "Add(2, 3) returns 5", $vResult, 5, $MATH_LIB_TESTS)
EndFunc

Func _RunMathLibTests($bWriteSummary = True)
    Local $bAllPassed = True
	
    $bAllPassed = _TestFmkRun(_TestAdd, $bAllPassed)
	
    If $bWriteSummary Then _TestFmkSummary()
    Return $bAllPassed
EndFunc

_TestFmkRunAllTests(_RunMathLibTests, $MATH_LIB_TESTS)
