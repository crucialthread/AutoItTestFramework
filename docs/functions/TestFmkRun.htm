Function Reference

_TestFmkRun

Executes a test function and returns True only if the test passed and no previous test had already failed.

#include <TestFramework.au3>
_TestFmkRun ( $hFuncTest [, $bNothingFailed = True] )

Parameters

$hFuncTestA function reference to the test function to run. Pass the function name directly without parentheses or quotes (e.g. _TestMyFunc, not "_TestMyFunc" or _TestMyFunc()).
Note: If the reference is invalid or the function cannot be called, a failure is recorded automatically.
$bNothingFailed[optional] The accumulated state from all previously run tests. Pass the accumulated variable here to carry the running total forward. Default is True.

Return Value

Success:True if this test produced no new failures AND $bNothingFailed is True.
Failure:False if this test produced at least one new failure, OR if $bNothingFailed was already False, OR if $hFuncTest is not a valid function reference.

Remarks

_TestFmkRun() snapshots the internal failure counter before calling $hFuncTest(), then compares it afterward. If the count increased, the test is considered failed and False is returned.

If $hFuncTest is not a valid function reference or cannot be called, _TestFmkRun() records a failure automatically and returns False.

_TestFmkRun() always runs every test function, regardless of whether previous tests have already failed. This is intentional: the full suite should always complete so you get a complete picture of what passes and fails in a single run, rather than stopping at the first failure.

The standard pattern is to chain the return value into the next _TestFmkRun() call, accumulating the result across the whole suite: 

Local $bAllPassed = True
$bAllPassed = _TestFmkRun(_TestA, $bAllPassed)
$bAllPassed = _TestFmkRun(_TestB, $bAllPassed)
$bAllPassed = _TestFmkRun(_TestC, $bAllPassed)

After all tests have run, the accumulated variable is True only if every test in the suite passed. This makes it usable as a return value from the test suite function for external callers that need a single pass/fail signal.

Related

_TestFmkHeader, _TestFmkAssert, _TestFmkSummary, _TestFmkRunAllTests

Example

#include <TestFramework.au3>

Local Const $MY_TESTS = "MyTests.au3"

Func _TestAdd()
    _TestFmkHeader("Test: Add() - returns correct sum")

    Local $vResult = 1 + 1

    _TestFmkAssert($vResult = 2, "1 + 1 = 2", $vResult, 2, $MY_TESTS)
EndFunc

Func _TestSubtract()
    _TestFmkHeader("Test: Subtract() - returns correct result")

    Local $vResult = 5 - 3

    _TestFmkAssert($vResult = 2, "5 - 3 = 2", $vResult, 2, $MY_TESTS)
EndFunc

Func _RunMyTests($bWriteSummary = True)
    Local $bAllPassed = True

    $bAllPassed = _TestFmkRun(_TestAdd,      $bAllPassed)
    $bAllPassed = _TestFmkRun(_TestSubtract, $bAllPassed)

    If $bWriteSummary Then _TestFmkSummary()
    Return $bAllPassed
EndFunc

_TestFmkRunAllTests(_RunMyTests, $MY_TESTS)
