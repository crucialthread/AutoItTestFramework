Function Reference

_TestFmkSeparator

Prints a separator line to the console to visually divide sections of output.

#include <TestFramework.au3>
_TestFmkSeparator ( [$iLength = 80 [, $sChar = "-" [, $vNewLineBefore = @CRLF [, $vNewLineAfter = @CRLF]]]] )

Parameters

$iLength[optional] The number of characters in the separator line. Default is 80.
$sChar[optional] The character to repeat to form the separator line. Default is "-".
$vNewLineBefore[optional] The string printed before the separator line. Default is @CRLF. Pass Null to suppress the leading newline.
$vNewLineAfter[optional] The string printed after the separator line. Default is @CRLF. Pass Null to suppress the trailing newline.

Return Value

None.This function does not return a value.

Remarks

Use _TestFmkSeparator() to visually divide groups of related tests from one another in the console output. The standard pattern is to call it at the start of each group function, just before the _TestFmkRun() calls for that group. This produces a separator line between each group in the output, making it easy to distinguish where one group ends and the next begins.

In a script that includes all test files, a wider separator using "=" characters is commonly used before the final combined summary to clearly mark the transition from individual test output to the overall result.

Output is suppressed when silent mode is active via _TestFmk_SetSilentMode(True).

Related

_TestFmkHeader, _TestFmkRun, _TestFmkSummary, _TestFmk_SetSilentMode

Example

#include <TestFramework.au3>
#include "MathLib.au3"

Local Const $MATH_LIB_TESTS = "MathLibTests.au3"

Func _TestAdd_ReturnsSum()
    _TestFmkHeader("Test: Add() - returns sum")
	
    Local $vResult = Add(2, 3)
	
    _TestFmkAssert($vResult = 5, "Add(2, 3) returns 5", $vResult, 5, $MATH_LIB_TESTS)
EndFunc

Func _TestAdd_NegativeNumbers()
    _TestFmkHeader("Test: Add() - negative numbers")
	
    Local $vResult = Add(-1, 1)
	
    _TestFmkAssert($vResult = 0, "Add(-1, 1) returns 0", $vResult, 0, $MATH_LIB_TESTS)
EndFunc

Func _TestSubtract_ReturnsResult()
    _TestFmkHeader("Test: Subtract() - returns result")
	
    Local $vResult = Subtract(5, 3)
	
    _TestFmkAssert($vResult = 2, "Subtract(5, 3) returns 2", $vResult, 2, $MATH_LIB_TESTS)
EndFunc

Func __RunMathLibTest_Add(ByRef $bAllPassed)
    _TestFmkSeparator()
    $bAllPassed = _TestFmkRun(_TestAdd_ReturnsSum,      $bAllPassed)
    $bAllPassed = _TestFmkRun(_TestAdd_NegativeNumbers, $bAllPassed)
EndFunc

Func __RunMathLibTest_Subtract(ByRef $bAllPassed)
    _TestFmkSeparator()
    $bAllPassed = _TestFmkRun(_TestSubtract_ReturnsResult, $bAllPassed)
EndFunc

Func _RunMathLibTests($bWriteSummary = True)
    Local $bAllPassed = True
	
    __RunMathLibTest_Add($bAllPassed)
    __RunMathLibTest_Subtract($bAllPassed)
	
    If $bWriteSummary Then _TestFmkSummary()
    Return $bAllPassed
EndFunc

_TestFmkRunAllTests(_RunMathLibTests, $MATH_LIB_TESTS)

Console output:

--------------------------------------------------------------------------------

+ --- Test: Add() - returns sum ---
> [PASS] Add(2, 3) returns 5

+ --- Test: Add() - negative numbers ---
> [PASS] Add(-1, 1) returns 0

--------------------------------------------------------------------------------

+ --- Test: Subtract() - returns result ---
> [PASS] Subtract(5, 3) returns 2
