Function Reference

_TestFmk_SetSilentMode

Enables or disables silent mode. In silent mode, pass and header output is suppressed - only failures, total count and failed count are printed.

#include <TestFramework.au3>
_TestFmk_SetSilentMode ( [$bSilent = False] )

Parameters

$bSilent[optional] A boolean value. Pass True to enable silent mode, False to disable it. Defaults to False. Non-boolean values are ignored and silent mode is set to False.

Return Value

None.This function does not return a value.

Remarks

When silent mode is enabled, the following output is suppressed:

  • Section headers printed by _TestFmkHeader()
  • Pass lines printed by _TestFmkAssert()
  • Separator lines printed by _TestFmkSeparator()
  • The Passed count line printed by _TestFmkSummary()

The following output is always printed regardless of silent mode:

  • Failure lines printed by _TestFmkAssert()
  • The Total and Failed count lines printed by _TestFmkSummary()

Silent mode is primarily useful when multiple test files are included and run together. Enabling it at the top of the script that includes all test files suppresses the individual pass output from each suite, leaving only failures visible and producing a clean combined summary at the end.

Related

_TestFmkHeader, _TestFmkAssert, _TestFmkSeparator, _TestFmkSummary, _TestFmkRunAllTests

Example

#include "MathLibTests.au3"
#include "FileCleanupTests.au3"

_TestFmk_SetSilentMode(True)

Func _RunAllTests()
    Local $bWriteSummary = False
    Local $bAllPassed    = True

    $bAllPassed = _RunMathLibTests($bWriteSummary)     And $bAllPassed
    $bAllPassed = _RunFileCleanupTests($bWriteSummary) And $bAllPassed

    _TestFmkSummary()

    Return $bAllPassed
EndFunc

Exit Not _RunAllTests()

+ Total: 12
: Failed: 0

+ Total: 12
! Failed: 1
