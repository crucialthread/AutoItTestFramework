Function Reference

_TestFmkSummary

Prints a final Total, Passed, and Failed count to the console at the end of a test run.

#include <TestFramework.au3>
_TestFmkSummary()

Parameters

None.This function takes no parameters.

Return Value

None.This function does not return a value.

Remarks

Call _TestFmkSummary() once at the end of the test suite function, after all test functions have been run via _TestFmkRun(). Calling it inside individual test functions would produce partial or incorrect totals.

The Failed line is printed in red ($TFW_COLOR_RED) when there are one or more failures, and in white ($TFW_COLOR_WHITE) when the count is zero, making a fully-passing suite immediately distinguishable from a suite with failures in SciTE's output pane.

The Total and Failed lines are always printed. The Passed line is suppressed when silent mode is active via _TestFmk_SetSilentMode(True). The summary block is bounded by = separator lines, which are also suppressed in silent mode.

When using the $bWriteSummary convention in a multi-suite context, pass False to the test suite function to skip the summary and let the script that includes all test files print a single combined one at the end.

Related

_TestFmkHeader, _TestFmkAssert, _TestFmkRun, _TestFmk_SetSilentMode

Example

#include <TestFramework.au3>

Local Const $MY_TESTS = "MyTests.au3"

Func _TestSomething()
    _TestFmkHeader("Test: Something")
	
    Local $bResult1 = True
    Local $bResult2 = False
    Local $bResult3 = True
	
    _TestFmkAssert($bResult1 = True,  "First assertion passes",  $bResult1, True,  $MY_TESTS)
    _TestFmkAssert($bResult2 = True,  "Second assertion fails",  $bResult2, True,  $MY_TESTS)
    _TestFmkAssert($bResult3 = True,  "Third assertion passes",  $bResult3, True,  $MY_TESTS)
EndFunc

Func _RunMyTests($bWriteSummary = True)
    Local $bAllPassed = True
	
    $bAllPassed = _TestFmkRun(_TestSomething, $bAllPassed)
	
    If $bWriteSummary Then _TestFmkSummary()
    Return $bAllPassed
EndFunc

_TestFmkRunAllTests(_RunMyTests, $MY_TESTS)

Console output:

+ --- Test: Something ---
> [PASS] First assertion passes
! [FAIL] Second assertion fails (actual: False, expected: True) [MyTests.au3 - Line: 10]
> [PASS] Third assertion passes

+ Total: 3
> Passed: 2
