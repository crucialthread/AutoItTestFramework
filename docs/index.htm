AutoIt Test Framework

AutoIt Test Framework is a lightweight unit test framework for AutoIt, with zero dependencies beyond AutoIt itself. It provides colored console output, cumulative pass/fail tracking, and actionable failure details - including full support for testing code that calls built-ins like dialogs, file system, registry, and GUI without those operations executing for real.

Designed to be used alongside any AutoIt script, AutoIt Test Framework makes it easy to write and run unit tests for your AutoIt code. Test results are printed directly to SciTE's console output pane, and suites can also be run from the command line as part of an automated workflow.

Key Features

Testable wrappers and stubsA pattern for testing code that calls AutoIt built-ins - dialogs, file system, registry, GUI - without those operations executing for real during tests.
Cumulative pass/fail resultsEvery test always runs regardless of earlier failures, giving you a complete picture of the suite in one run.
Clear failure outputOn failure, the actual and expected values are printed alongside the description, including the file name and line number of the failing assertion.
Colored console outputPass/fail results are color-coded in SciTE's output pane for at-a-glance readability.
Summary blockPrints a final Total, Passed, and Failed count to the console at the end of a test run.
Silent modeA mode that suppresses pass results and header output, leaving only failures and the final summary visible. Useful when running multiple test suites together.
Composable test suitesEach test file can run its own test suite independently or be part of a single combined script that aggregates all test files and executes their test suites altogether.
Command line supportTest suites can be run from the command line and report pass/fail via exit code, making them easy to integrate into build pipelines.
Zero dependenciesA single #include <TestFramework.au3> is all that is needed - no third-party libraries or external dependencies beyond AutoIt itself.

Quick Example

; MyFunc.au3

Func MyFunc($a, $b)
    Return $a + $b
EndFunc

; MyFuncTests.au3

#include <TestFramework.au3>
#include "MyFunc.au3"

Local Const $MY_TESTS = "MyFuncTests.au3"

Func _TestMyFunc()
    _TestFmkHeader("Test: MyFunc")
	
    Local $vResult1 = MyFunc(2, 3)
    Local $vResult2 = MyFunc(0, 0)
	
    _TestFmkAssert($vResult1 = 5, "MyFunc(2, 3) returns 5", $vResult1, 5, $MY_TESTS)
    _TestFmkAssert($vResult2 = 0, "MyFunc(0, 0) returns 0", $vResult2, 0, $MY_TESTS)
EndFunc

Func _RunMyFuncTests($bWriteSummary = True)
    Local $bAllPassed = True
	
    $bAllPassed = _TestFmkRun(_TestMyFunc, $bAllPassed)
	
    If $bWriteSummary Then _TestFmkSummary()
    Return $bAllPassed
EndFunc

_TestFmkRunAllTests(_RunMyFuncTests, $MY_TESTS)

Console output:

+ --- Test: MyFunc ---
> [PASS] MyFunc(2, 3) returns 5
> [PASS] MyFunc(0, 0) returns 0

+ Total: 2
> Passed: 2
: Failed: 0
