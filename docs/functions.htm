Function Reference

TestFramework.au3

Click a function name for full documentation.

_TestFmkHeader Prints a labeled section header to the console to identify a group of related tests. Resets stubs by default.
_TestFmkAssert Evaluates a condition, records pass or fail, and prints the result to the console.
_TestFmkRun Runs a test function by reference and accumulates its pass/fail result into a cumulative boolean.
_TestFmkSummary Prints the final Total/Passed/Failed summary block to the console.
_TestFmkSeparator Prints a separator line to the console. Used to visually divide groups of related tests within a test file or between test suites in a script that includes all test files.
_TestFmkRunAllTests Runs the test suite function only when the script is executed directly, not when included by another script.
_TestFmk_SetSilentMode Enables or disables silent mode. In silent mode, pass and header output is suppressed - only failures and the summary are printed.

Testable.au3

Provides _Tstbl_* wrapper functions for AutoIt built-ins. Include Testable.au3 in script code and use these wrappers instead of AutoIt built-ins directly so that calls can be intercepted by stubs in tests. See the Testable Reference for the full list of wrappers by category.

_Tstbl_MsgBox Testable wrapper for MsgBox.
_Tstbl_InputBox Testable wrapper for InputBox.
_Tstbl_FileExists Testable wrapper for FileExists.
_Tstbl_FileDelete Testable wrapper for FileDelete.
_Tstbl_RegRead Testable wrapper for RegRead.
_Tstbl_RegWrite Testable wrapper for RegWrite.
_Tstbl_GUICreate Testable wrapper for GUICreate.
_Tstbl_GUIGetMsg Testable wrapper for GUIGetMsg.
_Tstbl_GUICtrlGetHandle Testable wrapper for GUICtrlGetHandle.
_Tstbl_ShellExecute Testable wrapper for ShellExecute.
_Tstbl_* Many more wrappers available — see Testable Reference for the complete list.

Each wrapper routes the call through a function pointer global ($g_hFn_*). In script code these point to the real AutoIt built-ins. In test files, including TestFramework.au3 automatically rewires them to stubs.

Stubs

Including TestFramework.au3 in test files automatically wires all _Tstbl_* wrappers to stubs. Stubs record every call with its parameters and return controlled values so tests can verify behavior without executing real AutoIt built-ins. See the Stubs Reference for full details.

_ResetStubs() Clears all recorded calls and configured return values. Called automatically by _TestFmkHeader().
_SetStubReturn($sType, $iIdx, $vValue) Pre-configures the return value for the Nth call of a given stub type. Call before running the code under test.
_StubCallCount($sType) Returns the number of times a stub type was called. Safe to call even when the stub was never called.
_StubCall($sType, $iIdx, $sParam) Returns the recorded argument value for a given stub type, call index, and parameter name.
_GetStubCall($sType, $iIdx, $sParam) Alias for _StubCall() - use when reading a recorded argument for clarity.

StubConstants.au3

Optionally include StubConstants.au3 in test files for named constants that make stub calls more readable. Provides 1-based call index constants and parameter name constants. See the Constants Reference for the full list.

$_1st, $_2nd, $_3rd, ... Named 1-based call index constants for use with _SetStubReturn(), _StubCall(), and _GetStubCall().
$Param_Text, $Param_State, ... Named parameter constants for use with _StubCall() and _GetStubCall() to identify recorded arguments by name.
