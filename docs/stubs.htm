Stubs Reference

Overview

Stubs.au3 provides stub implementations for all _Tstbl_* wrappers defined in Testable.au3. Including TestFramework.au3 in a test file automatically includes Stubs.au3 and rewires all function pointer globals to stubs.

Each stub serves two purposes:

  • Call recording - every call is recorded with its parameters so tests can verify that the correct functions were called with the correct arguments using _GetStubCall(), and how many times via _StubCallCount().
  • Return control - tests can pre-configure what a stub returns for each call via _SetStubReturn(), allowing tests to drive the code under test down specific branches.

Usage

Include TestFramework.au3 in test files - it automatically includes Stubs.au3 and rewires all function pointers: 

; MyScriptTests.au3

#include <TestFramework.au3>
#include <StubConstants.au3>
#include "MyScript.au3"

Local Const $MY_SCRIPT_TESTS = "MyScriptTests.au3"

Func _TestSomething()
    _TestFmkHeader("Test: something")

    _SetStubReturn("MsgBox", $_1st, $IDYES)

    MyFunction()

    Local $iCount = _StubCallCount("MsgBox")
    Local $sTitle = _GetStubCall("MsgBox", $_1st, $Param_Title)
	
    _TestFmkAssert($iCount = 1,          "MsgBox called once",    $iCount, 1,         $MY_SCRIPT_TESTS)
    _TestFmkAssert($sTitle = "Confirm",  "MsgBox title correct",  $sTitle, "Confirm", $MY_SCRIPT_TESTS)
EndFunc

Func _RunMyScriptTests($bWriteSummary = True)
    Local $bAllPassed = True
	
    $bAllPassed = _TestFmkRun(_TestSomething, $bAllPassed)
	
    If $bWriteSummary Then _TestFmkSummary()
    Return $bAllPassed
EndFunc

_TestFmkRunAllTests(_RunMyScriptTests, $MY_SCRIPT_TESTS)

Functions

_ResetStubs()

_ResetStubs()

Clears all recorded calls and configured return values. Called automatically by _TestFmkHeader() at the start of each test group. Use this if you need to reset manually outside of a header call.

_SetStubReturn($sType, $iIdx, $vValue)

_SetStubReturn($sType, $iIdx, $vValue)

Pre-configures the return value for the Nth call of a given stub type. Call this before running the code under test to control which branches execute.

$sTypeThe stub type name as a string, e.g. "MsgBox", "FileExists", "RegRead".
$iIdxThe 1-based call index. 1 configures the return for the first call, 2 for the second, and so on. StubConstants.au3 provides named aliases: $_1st, $_2nd, etc.
$vValueThe value to return for that call. Pass $STUB_ERROR to simulate the stub setting @error = 1.
; First MsgBox returns YES, second returns NO
_SetStubReturn("MsgBox", $_1st, $IDYES)
_SetStubReturn("MsgBox", $_2nd, $IDNO)

; Simulate RegRead failing with @error
_SetStubReturn("RegRead", $_1st, $STUB_ERROR)

If no return is configured for a given call index the stub falls back to a sensible default (e.g. $IDOK for MsgBox, True for FileExists, empty string for RegRead).

_StubCallCount($sType)

_StubCallCount($sType)

Returns the number of times a stub type was called. Safe to call even when the stub was never called - returns 0 in that case. 

Local $iCount = _StubCallCount("FileDelete")
_TestFmkAssert($iCount = 1, "FileDelete called once", $iCount, 1, $MY_TESTS)

_StubCall($sType, $iIdx, $sParam)

_StubCall($sType, $iIdx, $sParam)

Returns the recorded argument value for a given stub type, call index, and parameter name. Returns Null when the stub was never called or the parameter does not exist.

_GetStubCall($sType, $iIdx, $sParam)

_GetStubCall($sType, $iIdx, $sParam)

Alias for _StubCall(). Use when reading a recorded argument for clarity. 

; Read the path passed to the first FileDelete call
Local $sPath = _GetStubCall("FileDelete", $_1st, $Param_Path)
_TestFmkAssert($sPath = "C:\temp\file.txt", "Correct file deleted", $sPath, "C:\temp\file.txt", $MY_TESTS)

Stub Data Stream

$g_StubCalls

Records every stub call with its arguments. Access via _StubCallCount() and _GetStubCall().

$g_StubReturns

Holds pre-configured return values set via _SetStubReturn(). Consulted by each stub when determining what to return for a given call index.

Recorded Call Properties

Each stub records the parameters passed to it as named properties on the call object.

Note:
Property names can be passed as raw strings (e.g. "sPath") or as named constants from StubConstants.au3 (e.g. $Param_Path).
Constants match by base name regardless of Hungarian prefix, so $Param_Path matches both "sPath" and "vPath".
See the Constants Reference for the full list.

Remarks

  • 1-based indexing. Call indexes start at 1. The first call to a stub is index 1, the second is index 2, and so on. Use _StubCallCount() to get the total number of calls - it is safe even when the stub was never called. StubConstants.au3 provides named aliases ($_1st, $_2nd, etc.) for call indexes.
  • Reading recorded arguments. Use _GetStubCall() to read a recorded argument by stub type, call index, and parameter name. It returns Null when the stub was never called or the parameter does not exist.
  • Simulating @error. Pass $STUB_ERROR as the return value to _SetStubReturn() to simulate a stub setting @error = 1. This works for all stubs.
  • Stubs reset automatically. _TestFmkHeader() calls _ResetStubs() automatically at the start of each test group. Use _ResetStubs() directly if you need to reset outside of a header call.
  • FileInstall. FileInstall requires a different approach to be testable. The stub records calls only when the script has registered a custom implementation via _Tstbl_Implement_FileInstall(). See FileInstall Special Case for details.
