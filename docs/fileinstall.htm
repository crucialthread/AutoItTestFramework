FileInstall Special Case

The Problem

FileInstall cannot be routed through a function pointer like other testable wrappers. Aut2Exe performs a static analysis pass over the source code at compile time, looking for FileInstall("literal string", ...) patterns to know which files to embed into the compiled exe. When FileInstall is called through a variable, Aut2Exe does not find it and the file is not embedded - causing the compiled exe to fail at runtime.

From the AutoIt official documentation:

  • The source file must be specified using a string literal and can not be a variable, a macro, a calculation nor function call.
  • The file must be able to be found during compiling, however variables, calculations and function calls do not get resolved until the script itself is running, long after compiling, making them unsuitable to define the source file.

The Solution

To make FileInstall testable, the script that needs to use FileInstall must define a custom function with a Select or If-ElseIf block where each call to FileInstall() uses a string literal, then register it via _Tstbl_Implement_FileInstall(). Aut2Exe finds the literal calls at compile time and embeds all files correctly, while the pointer can be replaced with a stub in tests. Example of what the script-side implementation should look like: 

Func __FileInstall($sSource, $sDest, $iFlag)
    Select
        Case $sSource = "file1.au3"
            FileInstall("file1.au3", $sDest, $iFlag)
        Case $sSource = "..\lib\file2.au3"
            FileInstall("..\lib\file2.au3", $sDest, $iFlag)
        Case $sSource = "..\tools\file3.exe"
            FileInstall("..\tools\file3.exe", $sDest, $iFlag)
    EndSelect
EndFunc

_Tstbl_Implement_FileInstall(__FileInstall)

In script code, call through the testable wrapper instead of calling FileInstall directly:

_Tstbl_FileInstall("file1.au3", $sDestFolder & "\file1.au3", $FC_OVERWRITE)
_Tstbl_FileInstall("..\lib\file2.au3", $sDestFolder & "\file2.au3", $FC_OVERWRITE)

Stubbing in Tests

In test files, Stubs.au3 wires the FileInstall stub automatically like any other stub. Call recording and return control work the same way as all other stubs. 

Global $__MY_SCRIPT_TEST_MODE = True
#include <TestFramework.au3>
#include <Stubs.au3>
#include "MyScript.au3"

Func _TestMyInstall()
    _TestFmkHeader("Test: install copies files")
    _ResetStubs()

    __RunInstall(1, 2)

    _TestFmkAssert($g_StubCalls["FileInstall"].count = 3, "Installs 3 files", $g_StubCalls["FileInstall"].count, 3)
    _TestFmkAssert($g_StubCalls["FileInstall"][1].sSource = "file1.au3", _
        "First file correct", $g_StubCalls["FileInstall"][1].sSource, "file1.au3")
EndFunc
The stub only records calls if the script under test has registered a custom implementation via _Tstbl_Implement_FileInstall(). If no implementation is registered, stub calls are ignored and False is returned.
